# Sistem Informasi Perpustakaan (SIPUS)

Repository ini berisi dokumentasi Sistem Informasi Perpustakaan yang dibuat untuk
Tugas 3 mata kuliah Sistem Informasi, Program Studi TRPL, Politeknik Negeri Bali.

## Deskripsi Singkat
SIPUS adalah sistem untuk membantu pengelolaan perpustakaan, seperti pendataan buku,
data anggota, serta transaksi peminjaman dan pengembalian buku. Sistem ini dirancang
supaya bisa diakses secara online dengan memanfaatkan layanan cloud computing.

## Pengguna Sistem
- Admin / Pustakawan
- Anggota (Mahasiswa dan Dosen)
- Kepala Perpustakaan

## Fitur Utama
- Pengelolaan data buku
- Pengelolaan data anggota
- Peminjaman dan pengembalian buku
- Perhitungan denda keterlambatan
- Laporan perpustakaan
